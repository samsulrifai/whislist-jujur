# Wishlist Jujur

Anti-impulsive buying MVP: cek barang sebelum checkout, dapat tier S/A/B/C/D, simpan wishlist, dan hitung uang yang terselamatkan.

## Screenshot

![Wishlist Jujur dashboard](docs/screenshot-dashboard.png)

## Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- localStorage

## Jalankan lokal

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Catatan MVP

- Tanpa login
- Tanpa backend
- Tanpa payment
- Tanpa scraping marketplace
- AI masih stub, belum memanggil API sungguhan
